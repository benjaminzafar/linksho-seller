# پنل فروش لینک شو (Next.js)

پروژه مستقل **پنل فروش** برای رستوران‌ها و فروشگاه‌های اینترنتی، آماده دیپلوی جداگانه روی Vercel.

## دیپلوی روی Vercel
1. این پوشه (`پنل فروش`) را به‌عنوان یک پروژه جداگانه در Vercel ایمپورت کنید (Framework Preset: **Next.js**).
2. در صورت تمایل متغیرهای محیطی زیر را تنظیم کنید (در غیر این صورت به‌صورت پیش‌فرض به پروژه Supabase متصل است):
   - `SUPABASE_URL`
   - `SUPABASE_ANON_KEY` (یا `SUPABASE_SERVICE_ROLE_KEY`)

## اتصال به آگهی‌ها در سایت اصلی
پس از ساخت فروشگاه یا رستوران در پنل فروش، یک **لینک API اختصاصی** (`/api/storefront?key=sk_live_...`) به فروشنده داده می‌شود. فروشنده این لینک را در فرم ثبت آگهی سایت اصلی قرار می‌دهد تا محصولات/منوی او مستقیماً داخل آگهی نمایش داده و فروخته شوند.
